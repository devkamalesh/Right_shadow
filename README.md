# Right Shadow – MLM Enterprise Platform

A full-stack Multi-Level Marketing (MLM) platform featuring an 18-level binary-tree hierarchy, Jarikai and Kerchief plans, member management, earnings calculations, payment workflows, and dedicated admin and user dashboards.

The platform combines responsive frontend interfaces with backend business logic, database optimization, and caching to support MLM operations and reporting.

## Live Application

- **Website:** [rightshadow.in](https://rightshadow.in/)
- **Admin Dashboard:** [rightshadow.in/admin](https://rightshadow.in/admin)
- **User Dashboard:** [rightshadow.in/user](https://rightshadow.in/user)

## Key Features

### MLM Management

- 18-level binary-tree member hierarchy.
- Separate Jarikai and Kerchief plans.
- Package-based eligibility and level-wise earnings calculations.
- Parent-child member relationship management.
- Monthly salary generation and earnings tracking.
- Hierarchical data retrieval and tree calculations.

### Admin Dashboard

- Member creation and parent assignment.
- Member management and administrative workflows.
- Payment verification and receipt management.
- Member information and plan-related operations.
- Reports with filtering and pagination.
- MLM analytics and earnings-related reporting.

### User Dashboard

- Member-specific dashboard and account information.
- Binary-tree hierarchy visualization.
- Individual-level calculations and earnings details.
- Plan and member-related information.
- Monthly salary and earnings reports.
- Responsive interface for dashboard workflows.

### Frontend Development

- Responsive interfaces built with React.js.
- Utility-based styling with Tailwind CSS.
- Animated transitions and interactions using Framer Motion.
- Redux-based application state management.
- Interactive dashboard components and hierarchy visualization.
- Integration with backend REST APIs.

### Backend Engineering

- REST API development for member management, dashboards, earnings, and reports.
- Business logic for binary-tree hierarchy and MLM plan calculations.
- Database transactions for multi-step operations.
- SQL query optimization and indexing.
- Efficient hierarchical data retrieval and tree calculations.
- Authentication, role-based access control, and request validation.
- Redis caching for frequently accessed data.
- Swagger API documentation.

## Architecture Highlights

- **Full-Stack Development:** Developed both React-based frontend interfaces and Node.js backend functionality.
- **Hierarchical Data Processing:** Manages parent-child member relationships across an 18-level binary tree.
- **Database Optimization:** Uses SQL query optimization and indexing to improve data retrieval.
- **Transaction Management:** Supports data consistency across multi-step database operations.
- **Caching:** Uses Redis to reduce repeated database reads where applicable.
- **State Management:** Uses Redux to manage frontend application state.
- **Interactive UI:** Uses Framer Motion for animations and Tailwind CSS for responsive styling.
- **Modular Backend:** Organizes API endpoints and business logic for maintainability.
- **Production Deployment:** Supports deployment and application management in a Linux server environment.
